O que construímos

Simples por fora. Um agente a sério por dentro.

🖥️ Interface

  • HTML, JS e CSS, sem framework
  • Investigação ao vivo e velocímetro
  • Catálogo e Como funciona
  • Português e inglês

⚙️ Backend

  • Node e Express
  • POST /desculpa
  • POST /conversa para o Messenger
  • Ferramentas em paralelo

🧠 IA

  • claude-sonnet-5-5
  • Tool use, até 12 voltas
  • Esforço médio na investigação
  • Resposta em JSON estruturado

🛟 Dados

  • Reais: Open-Meteo, Wikipédia
  • TomTom com chave
  • Sintéticos estáveis e marcados
  • Trocar por API real: 1 função

As mesmas 6 ferramentas também como servidor MCP. Qualquer agente as pode usar:

$ claude mcp add desculpometro -- node mcp-server.js
