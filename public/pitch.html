What we built

Simple on the outside. A real agent on the inside.

🖥️ Interface

  • HTML, JS and CSS, no framework
  • Live investigation and gauge
  • Catalogue and How it works pages
  • Portuguese and English

⚙️ Backend

  • Node and Express
  • POST /desculpa
  • POST /conversa for the Messenger
  • Tools run in parallel

🧠 AI

  • claude-sonnet-5-5
  • Tool use, up to 12 rounds
  • Medium effort for the investigation
  • Structured JSON output

🛟 Data

  • Real: Open-Meteo, Wikipedia
  • TomTom with a key
  • Stable, labelled synthetic data
  • Real API swap: 1 function

The same 6 tools also ship as an MCP server. Any agent can use them:

$ claude mcp add desculpometro -- node mcp-server.js
